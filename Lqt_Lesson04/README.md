# Lesson 04 - Views / Razor

Đã thay tên giảng viên xuất hiện trong ví dụ thành **Le Quoc Truong**.

Solution gồm 2 project theo video:
- LqtLesson04Review: ViewData, ViewBag, TempData và View `LqtContact`.
- LqtLesson04Views: Razor Code, biến, biểu thức, if/else, for và foreach.

Yêu cầu: .NET 8 SDK + Visual Studio 2022.

Mở `LeQuocTruong_Lesson04.sln` rồi chạy từng project.
